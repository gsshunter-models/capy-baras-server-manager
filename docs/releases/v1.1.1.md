# Capy Bara's Server Manager v1.1.1

Fixes automatic setup stopping with **file not found** when the manager's Windows firewall rule has not been created yet.

Windows can expose a missing firewall rule as a FileNotFoundException. The app now treats that specific missing-rule result as normal first-time setup and proceeds to its existing firewall helper. Removing a missing named rule is harmless as well; other firewall failures remain visible.

Saved profiles, encrypted DuckDNS tokens and existing server files carry over. No token reset is needed. Close the older manager and reopen the updated app before retrying **Set up & host**. Windows may ask to approve the firewall helper.

The Windows regression reproduces the previously failing rule lookup and now returns not configured, without creating or changing firewall rules. Credential encryption/isolation checks also pass.

Download the portable ZIP below, extract it completely, and run CapyBaraServerManager.exe. Windows and .NET 9 Desktop Runtime are required. Made with Codex.

# Capy Bara's Server Manager v1.1.0

Automatic setup and a hostname friends can enter directly in MX Simulator.

- One **Set up & host** flow configures the default game port, requests the Windows firewall rule and router mapping, updates DuckDNS, and starts the session.
- **Copy game address** supplies a plain `your-name.duckdns.org` hostname. Friends do not have to work out a port number.
- DuckDNS updates every five minutes while the relevant host/backend runs. Tokens are encrypted for the Windows account and profile, outside profile JSON and invites.
- **Automatic relay setup** configures the public backend's default game/tunnel ports, firewall, mapping, DNS and in-app relay. Local hosting pairs with that backend automatically.
- Existing manual controls and room invites remain available.

One-time DuckDNS login and name registration are required. Save the chosen name and account token in the app; Windows may ask to approve its firewall helper. DNS naming does not bypass CGNAT or blocked incoming connections: those still need a publicly reachable backend. No hosted relay service is provisioned. DNS can take time to propagate, and outside connectivity needs a friend to test.

Download the portable ZIP, extract all files, and run CapyBaraServerManager.exe. Requires Windows, .NET 9 Desktop Runtime, and MX Simulator; game hosts use their existing mxserver.exe folder.

Validation: DuckDNS syntax/default-port/provider/error/cancellation checks passed using synthetic HTTP responses. Windows credential encryption/isolation/JSON-exclusion tests passed. Native loopback server and room-network regressions passed. All seven screens rendered without starting public servers or changing actual DNS, firewall or router settings.

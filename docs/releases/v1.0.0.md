# Capy Bara's Server Manager v1.0.0

The first release of the capybara-and-orange MX Simulator server manager.

- Create and join sessions inside the app. The manager includes its own host tunnel, player tunnel and public relay backend. No Radmin, VPN driver or separate relay tool is required.
- Room invites connect a friend's game through a local endpoint and the manager's encrypted, certificate-pinned network. Host pairing and player invites have separate authority.
- Server profiles, erode, laps, minutes, bandwidth, player limits, native advanced options and live administration.
- Searchable trackinfo library, ordered rotations, per-track race settings, and imports watching the game's /savetrackinfo exports.
- Automatic router mapping requests, scoped firewall setup/removal, logs, player status and managed session files.

**A publicly reachable relay machine is still required for CGNAT/blocked hosts.** Run the backend inside another copy of this same app. This release does not deploy a hosted relay service. Direct hosting needs a reachable public UDP port. Real outside connectivity and latency must be tested on the target networks.

Download **CapyBaraServerManager-v1.0.0-windows-portable.zip**, extract all files, and run **CapyBaraServerManager.exe**. Requires Windows and the .NET 9 Desktop Runtime. MX Simulator is separate; hosts choose their existing mxserver.exe folder. Native server/game/mod files, private profiles, keys and trackinfos are not bundled.

Checks passed for native loopback hosting/admin commands/graceful stop, trackinfo validation/imports, argument ordering, profiles, TLS certificate rejection, multiple players, the in-app room bridge, 8 KB datagrams, a player leaving, and preventing player credentials from taking host authority. All seven screens rendered and the packaged app closed cleanly. Router/firewall settings were not changed during QA.
